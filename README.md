## 原生 IP 怎么自己验：三步，十分钟

商家页面写“Residential IP”，不等于你能用得顺。买之前用三个动作验证：

**第一步，查归属。** 到 ipinfo.io 输入 IP，看 ASN 和 Company 两项。Company 显示为运营商（Cox、Wave、AT&T 这类）而不是 hosting 商，才说明这段地址在数据库里挂的是 ISP 名下；ASN 归属同样应该是运营商。只要 Company 一栏是机房名字，所谓住宅属性在风控系统眼里就基本不存在。

**第二步，看风控分。** 用 scamalytics 查同一个 IP 的风险评分。同一段地址里不同 IP 的分数可能差很多，说明这段 IP 被混用得很厉害，分数高的那几个迟早会拖累你。

**第三步，ping 商家的测试 IP。** SixtyNet 方面，第三方整理给出过三个测试地址：高防和大硬盘系列 172.247.36.5，Cox 双 ISP 24.249.245.68，Wave 双 ISP 104.202.107.4。先 ping 延迟，再拿这三个 IP 走一遍前两步，比看任何宣传语都直接。

数据库口径这里有个坑要说清楚：不同库对“双 ISP”的识别并不一致，有的库认、有的库不认。所以别只看一个查询站的结果就下结论，至少交叉两个来源。

还有一层：**SixtyNet 官网在住宅线上只写了 Residential IP，没有写双 ISP，也没有写这批 IP 在各大数据库里的识别结果。** 第三方整理提到该系列默认是单 ISP，想换成 Cox 或 Wave 的家宽双 ISP 需要额外付费（整理口径是 $5），这属于配置选项，下单页能确认，但别把它当成默认赠送。

## 常见问题

**原生 IP 和广播 IP 的实际差别在哪？**
原生 IP 的地址段直接注册在美国本土 ISP 名下，地理归属在数据库里就是真实的美国运营商；广播 IP 只是靠 BGP 路由让你看起来在美国，流媒体识别、广告平台风控、Google 收录这些环节会露馅。判断方法就是上面那三步，不用听商家怎么说。

**为什么 SixtyNet 的住宅 IP 套餐要关掉 80 和 443？**
官网给的原因是 IP 风控。标准 Web 端口上跑流量，很容易被平台判定为机房用途，住宅 IP 的属性会被磨损。代价是这类套餐没法直接对外提供网站服务。

**ChatGPT 报 Access denied 是 IP 的问题吗？**
先用 ipinfo.io 确认出口 IP 的 Company 是不是运营商，再看 scamalytics 的分数。IP 干净还报错，问题往往在账号本身的风控状态，换 IP 解决不了。

**流量跑完了会直接停机吗？**
这一条 SixtyNet 的页面没有写，跟其他家做法差别很大（有的限速不断网，有的直接停）。下单前问客服，问清楚限速到多少。

**IP 被墙了怎么办？**
官网没有公开换 IP 政策。Pro 系列本身拒绝外部探测、只允许白名单访问，被墙后的处理方式需要开工单确认，不要默认有免费换 IP。
